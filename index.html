Persiapan Server & Instalasi Dependensi

A. Perbarui Sistem & Paket Esensial:
terminal 
sudo apt update && sudo apt upgrade -y
sudo apt install -y git curl unzip zip nginx mysql-server
B. Tambahkan PPA Resmi PHP & Pasang PHP 8.3:
terminal 
sudo apt install -y software-properties-common
sudo add-apt-repository -y ppa:ondrej/php
sudo apt update

sudo apt install -y php8.3 php8.3-cli php8.3-fpm php8.3-mysql php8.3-common \
    php8.3-xml php8.3-curl php8.3-mbstring php8.3-zip php8.3-bcmath \
    php8.3-intl php8.3-gd
C. Tetapkan PHP 8.3 sebagai Versi Default CLI:
terminal 
sudo update-alternatives --set php /usr/bin/php8.3
php -v

Pastikan output menunjukkan PHP 8.3.x agar tidak terjadi error version mismatch pada composer.

D. Pasang Composer & Node.js (LTS v20):
terminal 
# Pasang Composer
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

# Pasang Node.js LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

Kloning Repository & Build Aset

A. Clone Repository ke Direktori Web Server:
terminal 
cd /var/www
sudo git clone https://github.com/Masmas99/Masmas99
cd /var/www/Masmas99
B. Install Dependensi PHP & Compile Frontend:
terminal 
composer install --optimize-autoloader --no-dev
npm install
npm run build
3

Konfigurasi Database (MySQL)

Catatan Penting: Jangan gunakan user root MySQL untuk koneksi Laravel. Buat user tersendiri dengan izin akses ke host localhost dan 127.0.0.1.

A. Masuk ke MySQL Prompt:
terminal 
sudo mysql
B. Eksekusi Perintah SQL Berikut:
mysql console 
CREATE DATABASE IF NOT EXISTS `database`;
CREATE USER IF NOT EXISTS 'mashudiusername'@'localhost' IDENTIFIED BY 'PasswordKuat123#';
CREATE USER IF NOT EXISTS 'mashudiusername'@'127.0.0.1' IDENTIFIED BY 'PasswordKuat123#';
GRANT ALL PRIVILEGES ON `database`.* TO 'mashudiusername'@'localhost';
GRANT ALL PRIVILEGES ON `database`.* TO 'mashudiusername'@'127.0.0.1';
FLUSH PRIVILEGES;
EXIT;
4

Setup Environment (.env) & Migrasi Database

A. Buat File .env dan Application Key:
terminal 
cp .env.example .env
php artisan key:generate
B. Edit File .env:
terminal 
nano .env
Sesuaikan parameter konfigurasi berikut:
.env 
APP_NAME=Laravel
APP_ENV=local
APP_KEY="base64:xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
APP_DEBUG=true
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=database
DB_USERNAME=mashudiusername
DB_PASSWORD="PasswordKuat123#"

Simpan di Nano: tekan Ctrl + O lalu Enter, kemudian keluar dengan Ctrl + X.

C. Bersihkan Cache Config & Jalankan Migrasi:
terminal 
php artisan config:clear
php artisan migrate --force
php artisan storage:link
5

Pengaturan Permission Direktori & Optimasi Cache

A. Atur Kepemilikan dan Izin Tulis untuk Nginx (www-data):
terminal 
sudo chown -R www-data:www-data /var/www/absensi
sudo chmod -R 775 /var/www/absensi/storage /var/www/absensi/bootstrap/cache
B. Jalankan Cache Produksi:
terminal 
php artisan config:cache
php artisan route:cache
php artisan view:cache
6

Konfigurasi Nginx Server Block (Virtual Host)

A. Buat File Virtual Host:
terminal 
sudo nano /etc/nginx/sites-available/absensi
B. Isi dengan Konfigurasi Nginx Berikut:
/etc/nginx/sites-available/absensi 
server {
    listen 80 default_server;
    listen [::]:80 default_server;
    server_name absensi.domainanda.com;
    root /var/www/absensi/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php index.html;

    charset utf-8;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
C. Aktifkan Site & Reload Web Server:
terminal 
sudo rm -f /etc/nginx/sites-enabled/default
sudo ln -sf /etc/nginx/sites-available/absensi /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart php8.3-fpm
sudo systemctl reload nginx
7

Pasang SSL HTTPS (Certbot Let's Encrypt)

Wajib untuk Akses Kamera / GPS: Browser memblokir API perangkat keras (Kamera/Webcam & Geolocation) jika diakses lewat HTTP biasa (IP publik). Pasang SSL dengan Certbot:
A. Install Certbot Nginx:
terminal 
sudo apt install -y certbot python3-certbot-nginx
B. Daftarkan Sertifikat Domain:
terminal 
sudo certbot --nginx -d absensi.domainanda.com
C. Sesuaikan APP_URL di .env:
terminal 
# Buka nano .env dan ubah menjadi HTTPS:
# APP_URL=https://absensi.domainanda.com

# Kemudian refresh cache konfigurasi:
php artisan config:cache
Perintah berhasil disalin!
